# Version web d'origine

`index.html` est l'application web initiale (un seul fichier, données dans le
navigateur). Elle est conservée ici pour référence et comparaison.

L'application actuelle est le projet Flutter à la racine du dépôt : elle reprend
les mêmes fonctions et y ajoute la synchronisation entre appareils, l'import CSV
Desjardins, les notifications et les versions installables Windows et Android.

Pour ouvrir l'ancienne version : double-cliquer sur `index.html`.
